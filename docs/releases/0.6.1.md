This release keeps the menu bar controller alive for the full app session and checks that source files have not changed during release preparation.

If you have Sound Control 0.6.0, choose **Updates > Check for updates**, then **Update and restart**. Earlier versions need one manual installation to gain the updater.

The app supports Apple silicon and Intel Macs running macOS 13 or later. It is ad hoc signed and is not notarised by Apple; macOS may ask you to allow the first download in **System Settings > Privacy & Security**.
