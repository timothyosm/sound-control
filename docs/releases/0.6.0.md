Sound Control now checks for updates daily. Choose **Updates > Check for updates** to check at any time. When a version is available, choose **Update and restart** to install it without replacing the app yourself.

This release adds:

- signed release records and verified downloads
- a single app download for Apple silicon and Intel Macs running macOS 13 or later
- update preferences stored in SQLite
- recovery of the previous app if replacement or the relaunch command fails.

Existing versions do not contain an updater. Install this version once to receive future updates through the app. Quit Sound Control, download and unzip **SoundControl.zip**, then move **Sound Control.app** to Applications and open it.

This app is ad hoc signed and is not notarised by Apple. macOS may ask you to allow it in **System Settings > Privacy & Security** when you first open it. Release signatures verify future updates against the key included in the app; they do not replace Apple notarisation.
